## Интерпретация строгого протокола

- Четырёхчастное разделение: train → calibration → threshold → **independent model selection** → test.
  Калибратор и порог не видели записей, по которым выбиралась модель.
- По independent validation лучший E6 (HEAT, 0.7477), но на тесте его AFIB-F1 = 0.093 —
  подтверждение: высокий validation F1 не гарантирует качества на тесте.
- Лучший Chapman-тест у E4 CatBoost: F1=0.526 [0.496, 0.555], AFIB-F1=0.208.
- Сценарий unseen-source: один глобальный порог без source-specific калибровки.
  PTB-XL/CPSC-extra: AFL-F1 = 0, Balanced Accuracy ≈ 0.5 — переносимость не подтверждена.
- Причина завышенных select F1 (~0.74) vs test (~0.5): optimization на validation
  при surrogate grouping Chapman (record_id, нет настоящего patient_id). Все модели
  страдают одинаково — сравнение корректно, абсолютные значения нет.
- Bootstrap кластерный по `patient_key`; для Chapman это record-level surrogate,
  для PTB-XL — настоящий patient_id. Ограничение указано в каждой строке CSV.
